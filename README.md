# 三体运动模拟器 · Three-Body Problem

> 「宇宙就是一座黑暗森林。」——《三体》
> 这里不讲故事，只把万有引力定律原封不动地交给 GPU。

基于 **three.js** 的三体运动 3D 实时模拟器。三个天体在牛顿引力下互相拉扯，轨道实时积分、实时绘制，
并配备守恒诊断、混沌敏感性对照与九组经典初始构型。

---

## 快速开始

```bash
npm install          # 安装依赖（仅 three + vite）
npm run dev          # 开发模式，自动打开 http://localhost:5173
npm run build        # 构建到 dist/
npm run standalone   # 构建 + 额外产出 standalone.html（单文件版）
```

**单文件版 `standalone.html`（约 0.54 MB）**：双击即可用浏览器打开，无需服务器、无需联网，
所有 JS/CSS 都已内联。适合分享与离线演示。

---

## 功能

### 物理内核
- **Velocity Verlet 辛式积分**：二阶精度、时间可逆、长期能量不漂移。
  相比 RK4，辛式积分器把能量误差限制在 bounded oscillation 而非单向累积——这是「恒纪元」能撑多久的关键。
- **自适应步长**：由最近距离 `d_eff`、最大速度 `v_max`、最大加速度 `a_max` 共同约束，
  且**在子步循环内部每 16 步重估一次**（否则时间倍率拉高时，帧中途突发的近距离飞越会被整个错过）。
- **主动降速保护**：当所需子步数超过上限时，宁可让模拟时间变慢，也不放大步长硬闯。
  HUD 会显示 `⚠ 近距飞越降速 ×0.67`。
- **Plummer 软化引力** `a = G·Σ m_j·r⃗_ij / (r² + ε²)^{3/2}`，ε 可调；
  势能用与之严格对应的 `U = −G·m_i·m_j / √(r²+ε²)`，保证能量守恒判定自洽。

### 交互
- **视角**：左键旋转 / 滚轮缩放 / 右键平移；四个预设机位；切换预设时自动取景。
- **实时调参**：三个天体的质量、位置、初速度全部可拖动滑块即时改写（质量用对数滑块，覆盖 1e-3 ~ 1e4）。
- **时间**：暂停 / 单步 / 0.05× ~ 8× 变速 / 重置。
- **轨道拖尾**：定长环形缓冲 + 自定义着色器实现「越旧越淡、越旧越暗」的彗尾；长度与亮度可调。
- **视觉**：UnrealBloom 泛光、程序化生成的星云穹顶与 5200 颗星、参考网格、质心标记。

### 四项增强
| 能力 | 说明 |
|---|---|
| 经典周期解预设 | 八字形（Chenciner–Montgomery）、拉格朗日等边三角形、蝴蝶 I、熊蜂、飞蛾 I、阴阳 I、护目镜、日·地·月层级系统、三维混沌 |
| 守恒监测仪表盘 | 实时显示 E / T / U / \|P\| / \|L\| / 质心漂移 + 对数纵轴漂移曲线（能量、角动量、幽灵分离三条） |
| 混沌敏感性演示 | 「幽灵宇宙」：复制一份初值并施加 1e-12 ~ 1e-1 的扰动，用半透明线框分身对比展示轨迹指数分离 |
| 时间控制与导出 | 暂停/单步/变速、轨迹 CSV（19 列 × 最多 3000 帧）、画面 PNG 截图 |

### 快捷键
| 键 | 作用 | 键 | 作用 |
|---|---|---|---|
| `空格` | 暂停 / 继续 | `G` | 参考网格 |

## 物理正确性自检

```bash
node scripts/verify-physics.mjs
```

当前 **25 / 25 全部通过**：

| 检验项 | 结果 |
|---|---|
| 八字形轨道 · 一周期后位置闭合 | 误差 1.7e-8 |
| 八字形 · 100 个周期后能量漂移 | 5.6e-7 % |
| 八字形 · 总动量 / 质心漂移 | \|P\| = 4.8e-14，\|R_com\| = 2.9e-11 |
| 拉格朗日三角 · 一周期闭合 / 半径恒定 | 误差 1.1e-7 / 1.000000 → 1.000000 |
| 蝴蝶 / 熊蜂 / 飞蛾 / 阴阳 / 护目镜 · 周期闭合 | 2.0e-4 ~ 9.7e-4 |
| 上述五者 · t=60 能量漂移 | 6.1e-7 % ~ 3.3e-4 % |
| 二体退化 · 10 圈后半径 | 0.50000000（期望 0.5） |
| 日·地·月 · t=30 能量守恒 / 卫星未被甩飞 | 7.3e-12 % / 间距 0.416 < 希尔半径 1.39 |
| 时间可逆性 · 速度取反往返 t=5 | 回到初始位置误差 5.2e-10 |

> 注：Šuvakov–Dmitrašinović 族（蝴蝶、熊蜂等）是「近碰撞」自由落体轨道，最近距离可达 1e-2，
> 且文献初值只给到 5 位小数，因此闭合误差存在约 1e-3 的固有下界——再收紧步长也不会更小。
> 这也是为什么它们的默认软化因子取 ε = 0（软化会改变有效引力，反而破坏周期闭合）。

## 单位制

无量纲化：G = 1，质量量级 1，距离量级 1。
这样八字形轨道等文献初始条件可以照搬数值，无需换算。
面板显示的「模拟时间 t」即该单位制下的时间。

---

## 已知边界

- 三体系统本质混沌：除拉格朗日三角形等少数稳定构型外，长时间运行后轨迹必然发散，
  这是物理真实而非数值错误。守恒诊断面板可以用来区分「物理发散」与「数值失真」。
- 若用户把 ε 设为 0 又构造出真正的碰撞初值，积分器会触发降速保护（画面变慢而非崩坏），
  但极深碰撞仍可能把某个天体高速甩出——这是牛顿引力的真实行为。
